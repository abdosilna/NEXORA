# NEXORA BOT — بوت واتساب التعليمي بالذكاء الاصطناعي

منصة **NEXORA BOT** التعليمية التفاعلية عبر واتساب باستخدام مكتبة **Baileys** (`@whiskeysockets/baileys`)، مبنية بمعمارية معيارية متكاملة (Node.js ES Modules + إضافات `plugins/` + طبقة بيانات SQLite دائمة + لوحة تحكم إدارية خاصة).

> **تنويه تقني وقانوني مهم:**
> يعتمد هذا المشروع على مكتبة **Baileys** للاتصال بواتساب عبر بروتوكول WhatsApp Web متعدد الأجهزة، وهي **تكامل غير رسمي** وليست واجهة Meta Cloud API الرسمية. قد تتعرض التحديثات المستقبلية أو الحسابات لتغييرات أو قيود من واتساب وفق سياساته.

---

## أبرز القدرات والمحتوى التعليمي الفعلي

1. **واجهة واتساب عربية منظمة وتفاعلية:**
   - إرسال قوائم تفاعلية أصلية (`Interactive List` / `NativeFlow`) متى دعمها إصدار Baileys والعميل (`WHATSAPP_INTERACTIVE_MENUS=true`)، مع سقوط تلقائي سلس إلى قوائم مرقمة واضحة.
   - تنقل متعدد المستويات (`رجوع`، `رئيسية`، `إلغاء`، `مساعدة`) والتحقق من كل مدخل بدون عرض أي أخطاء تقنية خام للمستخدم.
   - تقسيم ذكي للرسائل الطويلة يحافظ على سلامة كتل الأكواد البرمجية.

2. **المساعد الذكي والمعلم الشخصي التكيفي (`AI Tutor`):**
   - يجيب باللغة العربية الطبيعية على الأسئلة التعليمية والعامة مع حفظ سياق المحادثة.
   - يتكيّف مع مستوى المتعلم (`beginner` / `intermediate` / `advanced`) ويتحقق من موافقة المستخدم الصريحة على ذاكرة التعلم (`memory_consent`).
   - في حال غياب مفتاح الذكاء الاصطناعي أو تعطل المزوّد، يشرح المشكلة بصدق ووضوح دون اختلاق إجابات وهمية.

3. **محرك بحث مستقل متعدد المصادر (`multi`):**
   - يجمع ويفحص النتائج من مصادر متعددة (DuckDuckGo و MDN Web Docs وقاعدة المعرفة الداخلية وويكيبيديا كمصدر اختياري) مع ذكر الروابط الموثقة وفصل الحقائق عن نقاط عدم اليقين.
   - يدعم مزوّدي `serper` و `brave` عند توفير `SEARCH_API_KEY`، وينبّه بوضوح عند اختيارهما بدون مفتاح.

4. **أكاديمية اللغات الكاملة (80+ درساً حقيقياً):**
   - **الإنجليزية، اليابانية، الروسية، الصينية**.
   - **20+ درساً حقيقياً للمستوى المبتدئ لكل لغة** مقسّمة إلى 4 وحدات منظمة، إضافة إلى دروس للمستويين المتوسط والمتقدم.
   - مفردات مترجمة، قواعد، أمثلة، دليل نطق، اختبارات متعددة الأسئلة، تكرار متباعد (SRS)، ومراجعة الأخطاء السابقة.

5. **أكاديمية البرمجة الكاملة:**
   - مسارات **Python، JavaScript، HTML، CSS، و Node.js** بدروس متدرجة، أمثلة كود عملية، مخرجات متوقعة، أخطاء شائعة، تمارين، ومشاريع صغيرة تطبيقية.
   - مساعد تصحيح الأخطاء عبر التحليل الساكن الآمن دون تنفيذ كود المستخدم على الخادم.

## مصفوفة المفاتيح والمتطلبات (ماذا يعمل فوراً وماذا يحتاج مفتاح API؟)

| الميزة / الوحدة | العمل بدون مفتاح خارجي | يتطلب مفتاح API |
|---|---|---|
| ربط واتساب بالاقتران (8 أرقام) والقوائم | يعمل بالكامل (`WHATSAPP_NUMBER`) | — |
| أكاديمية اللغات (80+ درساً) واختباراتها | يعمل بالكامل محلياً من SQLite | — |
| أكاديمية البرمجة والمشاريع والاختبارات | يعمل بالكامل محلياً من SQLite | — |
| التكرار المتباعد ومراجعة الأخطاء ولوحة الإدارة | يعمل بالكامل محلياً من SQLite | — |
| البحث المستقل (`SEARCH_PROVIDER=multi`) | يعمل (DuckDuckGo + MDN + قاعدة المعرفة) | `serper` و `brave` يتطلبان `SEARCH_API_KEY` |
| المعلم الذكي والمحادثة (`AI_PROVIDER=gemini`) | يوضح بصراحة أن الخدمة غير مفعّلة | يتطلب `AI_API_KEY` أو `GEMINI_API_KEY` |
| النطق الصوتي (`TTS_PROVIDER`) | يعرض دليل النطق النصي | `elevenlabs` / `openai` يتطلبان `TTS_API_KEY` |

## خطوات التثبيت والتشغيل السريع

- **المتطلبات:** Node.js **20.0.0 أو أحدث** (مختبر على Node.js 22 LTS).

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   ```bash
   cp .env.example .env
   ```
   أهم المتغيرات:
   - `PORT`: منفذ الخادم (الافتراضي `3000`).
   - `WHATSAPP_NUMBER`: رقم هاتف واتساب الدولي بدون `+` أو أصفار بادئة (مثال `966501234567`).
   - `WHATSAPP_INTERACTIVE_MENUS`: `true` لتفعيل القوائم التفاعلية الأصلية مع السقوط التلقائي للقوائم المرقمة.
   - `APP_SECRET`: مفتاح سري عشوائي للجلسات الإدارية.
   - `AI_PROVIDER=gemini`, `AI_MODEL=gemini-4-hydrogen`, `AI_API_KEY=...` (اختياري للمساعد الذكي).
   - `SEARCH_PROVIDER=multi` (الافتراضي ويعمل بدون مفتاح)، أو `serper` / `brave` مع `SEARCH_API_KEY`.
   - `TTS_PROVIDER=disabled` (افتراضي) أو مزود صوتي مدعوم.

3. **تهيئة قاعدة البيانات والمنهج الكامل:**
   ```bash
   npm run setup
   ```

4. **تشغيل البوت:**
   ```bash
   npm start
   ```

## ربط واتساب عبر رمز الاقتران (8 خانات — بدون QR)

1. ضع رقمك الدولي في `WHATSAPP_NUMBER` داخل `.env` أو إعدادات لوحة الاستضافة.
2. شغّل البوت عبر `npm start`.
3. سيُطبع رمز الاقتران المكون من 8 خانات **في وحدة تحكم الخادم الخاصة فقط (Console)**.
4. من تطبيق واتساب على هاتفك:
   `الأجهزة المرتبطة (Linked Devices)` ← `ربط جهاز (Link a Device)` ← `الربط برقم الهاتف بدلاً من ذلك` ← أدخل الرمز.
5. تُحفظ بيانات الجلسة ذرياً داخل `data/auth`.
6. **عند ظهور حالة `401 / loggedOut`:** يتوقف البوت عن إعادة المحاولة تلقائياً؛ احذف مجلد `data/auth` فقط وأعد تشغيل البوت لطلب رمز اقتران جديد. **لن تُحذف بيانات المستخدمين أو تقدمهم في SQLite أبداً.**

## التشغيل على Pterodactyl / NexoPanel

- **ملف التشغيل الرئيسي:** `index.js`
- **أمر البدء (Startup Command):** `npm start`
- **عنوان الاستماع:** `0.0.0.0` على المنفذ `process.env.PORT`
- **فحص الجاهزية:** `GET /health`
- **لوحة الإدارة الخاصة:** `http://<host>:<port>/admin`

# NEXORA BOT — بوت واتساب التعليمي بالذكاء الاصطناعي

منصة **NEXORA BOT** التعليمية التفاعلية عبر واتساب باستخدام مكتبة **Baileys** (`@whiskeysockets/baileys`)، مصممة بهيكلية وحدات نظيفة بـ Node.js ES Modules وقاعدة بيانات SQLite دائمة مع لوحة تحكم إدارية خاصة.

> **تنويه تقني وقانوني مهم:**
> يعتمد هذا المشروع على مكتبة **Baileys** للاتصال بواتساب عبر بروتوكول WhatsApp Web متعدد الأجهزة، وهي **تكامل غير رسمي** وليست واجهة Meta Cloud API الرسمية. قد تتعرض التحديثات المستقبلية أو الحسابات لتغييرات أو قيود من واتساب وفق سياساته.

---

## المتطلبات الأساسية

- **Node.js**: الإصدار **20.0.0 أو أحدث** (مُختبر على Node.js 22 LTS).
- **نظام التشغيل**: Linux (متوافق مع استضافات **Pterodactyl** و **NexoPanel** دون الحاجة إلى Docker أو `ts-node`).

---

## خطوات التثبيت والتشغيل السريع

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   انسخ ملف `.env.example` إلى `.env` ثم عيّن القيم:
   ```bash
   cp .env.example .env
   ```
   أهم المتغيرات:
   - `PORT`: منفذ الخادم (مثال `3000` أو منفذ لوحة Pterodactyl).
   - `WHATSAPP_NUMBER`: رقم هاتف واتساب الدولي بدون `+` أو أصفار بادئة (مثال `966501234567`) لطلب رمز الاقتران المكون من 8 خانات.
   - `APP_SECRET`: مفتاح سري عشوائي طويل للجلسات.
   - `AI_PROVIDER` و `AI_API_KEY` و `AI_MODEL`: اختياري لتفعيل المعلم الذكي (`gemini` أو `openai` أو `anthropic` أو `disabled`).
   - `SEARCH_PROVIDER` و `SEARCH_API_KEY`: اختياري (`wikipedia` يعمل مجاناً بدون مفتاح، أو `duckduckgo` / `serper` / `brave`).
   - `TTS_PROVIDER` و `TTS_API_KEY`: اختياري لتحويل النص إلى نطق صوتي (`disabled` افتراضياً).

3. **تهيئة قاعدة البيانات:**
   ```bash
   npm run setup
   ```

4. **تشغيل البوت:**
   ```bash
   npm start
   ```

## ربط واتساب عبر رمز الاقتران (8 خانات — بدون QR)

1. تأكد من وضع رقمك الدولي في `WHATSAPP_NUMBER` داخل `.env` أو متغيرات اللوحة.
2. شغّل البوت عبر `npm start`.
3. سيُطبع رمز الاقتران المكون من 8 خانات **في وحدة تحكم الخادم الخاصة فقط (Console)**.
4. من تطبيق واتساب على هاتفك:
   `الأجهزة المرتبطة (Linked Devices)` ← `ربط جهاز (Link a Device)` ← `الربط برقم الهاتف بدلاً من ذلك` ← أدخل الرمز.
5. تُحفظ بيانات الجلسة بأمان وذرياً داخل `data/auth`.
6. **عند ظهور حالة `401 / loggedOut`:** يتوقف البوت عن إعادة المحاولة تلقائياً لحماية الحساب؛ احذف مجلد `data/auth` فقط وأعد تشغيل البوت لطلب رمز اقتران جديد. **لن تُحذف بيانات المستخدمين أو الدروس في SQLite أبداً.**

## التشغيل على Pterodactyl / NexoPanel

- **ملف التشغيل الرئيسي:** `src/index.js`
- **أمر البدء (Startup Command):** `npm start`
- **عنوان الاستماع:** `0.0.0.0` على المنفذ `process.env.PORT`
- **فحص الجاهزية (Health Endpoint):** `GET /health`
- **لوحة الإدارة الخاصة:** `http://<host>:<port>/admin` (في أول تشغيل، أنشئ حساب المشرف الأول مباشرة من الصفحة، وبعدها تُغلق عملية الإنشاء العام تلقائياً).

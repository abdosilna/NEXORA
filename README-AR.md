# NEXORA BOT — بوت واتساب التعليمي بالذكاء الاصطناعي

منصة **NEXORA BOT** التعليمية التفاعلية عبر واتساب باستخدام مكتبة **Baileys** (`@whiskeysockets/baileys`)، مبنية بمعمارية معيارية متكاملة (Node.js ES Modules + 9 إضافات `plugins/` + قاعدة بيانات SQLite دائمة عبر 5 ترحيلات + لوحة تحكم إدارية خاصة).

> **تنويه تقني وقانوني مهم:**
> يعتمد هذا المشروع على مكتبة **Baileys** للاتصال بواتساب عبر بروتوكول WhatsApp Web متعدد الأجهزة، وهي **تكامل غير رسمي** وليست واجهة Meta Cloud API الرسمية. قد تتعرض التحديثات المستقبلية أو الحسابات لتغييرات أو قيود من واتساب وفق سياساته.

---

## أبرز القدرات والقائمة التفاعلية ذات الأقسام التسعة

1. **واجهة واتساب عربية تفاعلية بالكامل (9 أقسام رئيسية):**
   - المعلم الذكي، أكاديمية اللغات، أكاديمية البرمجة، البحث الذكي، الذكاء الصوتي، الاستوديو الإبداعي، مكتبة الأنمي والمعرفة، تقدّمي التعليمي، والمساعدة والإعدادات.
   - قوائم تفاعلية أصلية (`single_select` و `quick_reply`) عند تفعيل `WHATSAPP_INTERACTIVE_MENUS=true` مع سقوط تلقائي سلس إلى قوائم مرقمة واضحة، ودعم التصفح بالصفحات (`التالي` / `السابق`) وتنقل دائم (`رجوع`، `رئيسية`، `إلغاء`، `مساعدة`).
   - المرجع البصري لهوية نيكسورا الليلية: [`docs/design/nexora-mobile-menu-mockup.jpg`](docs/design/nexora-mobile-menu-mockup.jpg).

2. **المساعد الذكي والمعلم الشخصي التكيفي (`AI Tutor`):**
   - يستخدم `@google/genai` مع معالجة خاصة لسلسلة **Gemini 4** (`gemini-4-hydrogen`) بتمرير توجيه الطول في `systemInstruction` دون تقييد `maxOutputTokens` الذي يستهلكه التفكير الداخلي.
   - يحافظ على سياق المحادثة بالعربية ويتحقق من موافقة المستخدم الصريحة على حفظ الذاكرة التعليمية (`memory_consent`)، ويوضح بصراحة أي نقص في المفاتيح دون اختلاق ردود.

3. **محرك البحث الذكي متعدد المصادر (`SEARCH_PROVIDER=multi`):**
   - يجمع النتائج من DuckDuckGo و MDN Web Docs وقاعدة المعرفة الداخلية وويكيبيديا مع حماية SSRF وروابط موثقة.

4. **أكاديمية اللغات الكاملة (80+ درساً حقيقياً):**
   - **اليابانية، الإنجليزية، الروسية، الصينية** (أكثر من 20 درساً للمستوى المبتدئ لكل لغة + مستويين متوسط ومتقدم)، مع اختبارات متعددة الأسئلة، التكرار المتباعد (SM-2 SRS)، ومراجعة الأخطاء.

5. **أكاديمية البرمجة المتدرجة (مبتدئ ← متوسط ← متقدم):**
   - مسارات **Python، HTML، CSS، JavaScript، و Node.js** كاملة بالمستويات الثلاثة مع تصفية المستوى، أمثلة الكود، المخرجات المتوقعة، الأخطاء الشائعة، مشاريع ختامية (`project`)، اختبارات، وتحليل ساكن آمن للأكواد دون تنفيذها على الخادم.

6. **الاستوديو الإبداعي وتوليد الصور (`Creative Studio`):**
   - يولّد صوراً تعليمية وإبداعية آمنة عبر `IMAGE_PROVIDER` (`gemini` باستخدام `gemini-3.1-flash-lite-image` أو `openai`) مع أبعاد قابلة للاختيار (`1:1`، `16:9`، `9:16`)، وفحص أمان للأوامر، والتحقق من الصيغ (`PNG/JPEG/WebP`) والحد الأقصى للحجم (`5MB`) وتنظيف الملفات المؤقتة تلقائياً بعد الإرسال.

7. **الخصوصية وحماية البيانات:**
   - لا تُعرض محادثات المستخدمين الخاصة أبداً للمشرفين في لوحة التحكم؛ ويستطيع المتعلم تصدير ملخص بياناته أو حذف حسابه بالكامل في أي وقت.

## مصفوفة المفاتيح والمتطلبات (ماذا يعمل فوراً وماذا يحتاج مفتاح API؟)

| الميزة / الوحدة | العمل بدون مفتاح خارجي | يتطلب مفتاح API |
|---|---|---|
| ربط واتساب بالاقتران (8 أرقام) والقائمة التفاعلية (9 أقسام) | يعمل بالكامل (`WHATSAPP_NUMBER`) | — |
| أكاديمية اللغات (80+ درساً) واختباراتها | يعمل بالكامل محلياً من SQLite | — |
| أكاديمية البرمجة (مبتدئ ← متوسط ← متقدم) والمشاريع | يعمل بالكامل محلياً من SQLite | — |
| مكتبة الأنمي والمعرفة + التقدم + التكرار المتباعد | يعمل بالكامل محلياً من SQLite | — |
| البحث المستقل (`SEARCH_PROVIDER=multi`) | يعمل (DuckDuckGo + MDN + قاعدة المعرفة) | `serper` و `brave` يتطلبان `SEARCH_API_KEY` |
| المعلم الذكي والمحادثة (`AI_PROVIDER=gemini`) | يوضح بصراحة أن الخدمة غير مفعّلة | يتطلب `AI_API_KEY` أو `GEMINI_API_KEY` |
| الاستوديو الإبداعي (`IMAGE_PROVIDER`) | يعرض حالة التعطيل وإرشادات الضبط بوضوح | `IMAGE_API_KEY` (أو `GEMINI_API_KEY` مع `gemini`) |
| النطق الصوتي (`TTS_PROVIDER`) | يعرض دليل النطق النصي | `elevenlabs` / `openai` يتطلبان `TTS_API_KEY` |

## خطوات التثبيت والتشغيل السريع

- **المتطلبات:** Node.js **20.0.0 أو أحدث** (مختبر على Node.js 22 LTS).

1. **تثبيت الحزم:**
   ```bash
   npm install
   ```
2. **إعداد متغيرات البيئة:**
   ```bash
   cp .env.example .env
   ```
   أهم المتغيرات: `PORT`، `WHATSAPP_NUMBER`، `WHATSAPP_INTERACTIVE_MENUS=true`، `APP_SECRET`، `AI_PROVIDER=gemini`، `AI_MODEL=gemini-4-hydrogen`، `AI_API_KEY`، `IMAGE_PROVIDER`، `IMAGE_API_KEY`، `IMAGE_MODEL`، `SEARCH_PROVIDER=multi`، `TTS_PROVIDER=disabled`.
3. **تهيئة قاعدة البيانات والمنهج الكامل:**
   ```bash
   npm run setup
   ```
4. **تشغيل البوت:**
   ```bash
   npm start
   ```

## ربط واتساب عبر رمز الاقتران (8 خانات — بدون QR)

1. ضع رقمك الدولي في `WHATSAPP_NUMBER` داخل `.env` أو إعدادات لوحة الاستضافة.
2. شغّل البوت عبر `npm start`.
3. سيُطبع رمز الاقتران المكون من 8 خانات **في وحدة تحكم الخادم الخاصة فقط (Console)**.
4. من تطبيق واتساب على هاتفك:
   `الأجهزة المرتبطة (Linked Devices)` ← `ربط جهاز (Link a Device)` ← `الربط برقم الهاتف بدلاً من ذلك` ← أدخل الرمز.
5. تُحفظ بيانات الجلسة ذرياً داخل `data/auth`.
6. **عند ظهور حالة `401 / loggedOut`:** يتوقف البوت عن إعادة المحاولة تلقائياً؛ احذف مجلد `data/auth` فقط وأعد تشغيل البوت لطلب رمز اقتران جديد. **لن تُحذف بيانات المستخدمين أو تقدمهم في SQLite أبداً.**

## التشغيل على Pterodactyl / NexoPanel

- **ملف التشغيل الرئيسي:** `index.js`
- **أمر البدء (Startup Command):** `npm start`
- **عنوان الاستماع:** `0.0.0.0` على المنفذ `process.env.PORT`
- **فحص الجاهزية:** `GET /health`
- **لوحة الإدارة الخاصة:** `http://<host>:<port>/admin`
